## Introduction to Computers

A computer is an electronic device that accepts data as input, processes it according to instructions, stores information, and produces useful output.

Computers are used in many areas of modern life, including education, business, communication, healthcare, science, and entertainment.

*Computers have become an essential part of modern society.*

## Types of Computers

| Category | Primary Function | Typical Examples |
| :--- | :--- | :--- |

| **Mainframe Computers** | Bulk data processing and financial transactions | IBM zSeries |

## 3. History of Computers

Computing hardware has evolved through five distinct generations:

1. **First Generation (1940–1956):** Relied on vacuum tubes for circuitry and magnetic drums for memory (e.g., ENIAC).
2. **Second Generation (1956–1963):** Replaced vacuum tubes with transistors, reducing size and power consumption.
3. **Third Generation (1964–1971):** Implemented Integrated Circuits (ICs) on semiconductor chips.
4. **Fourth Generation (1971–Present):** Powered by microprocessors containing thousands of integrated circuits on a single chip.
5. **Fifth Generation (Present & Future):** Centers on artificial intelligence, parallel computing, and quantum mechanics.
